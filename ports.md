Port Assignments
-----

Port assignment convention (shared across all SunshineCTF archive years):

    port = yycnn

- `yy` = last two digits of the competition year (20 for 2020)
- `c`  = category: 0 pwn, 1 reversing, 2 scripting, 3 web, 4 crypto,
        5 misc (also forensics/other), 6 speedrun, 7 pegasus
- `nn` = challenge index within the category

For 2020 the challenges are numbered starting at 01, ordered by point value then
name, except the speedruns, whose `nn` matches the speedrun number (00-17).

Pegasus ports (207nn) are reserved and handled separately (the Pegasus submodule
is out of scope for this archive); they are not listed here.

Only hosted challenges (those with a running server component) are listed.
